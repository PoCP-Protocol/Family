## 一、项目本质(裁决:方向 CORRECT,闭环措辞修正)

**Family = 面向 12–15 岁家庭的「共同成长操作系统」**,不是聊天机器人、课程商城或测评工具。

产品战略层可讲 `State → Decision → Action → Outcome → Learning`。
但进入 Ontology / Runtime,坚持更严格的:

```
State → Decision → Action → Observation → Review → Learning Input
```

理由:**Observation ≠ Outcome,Outcome ≠ Fact**。否则会从「一次打卡」直接跳成「干预有效」。

宪法级硬规则(代码+CI 已兜住):核心状态只走 Named Action;AI 不直写 Ontology;模型必经 Gateway;高风险过 Human Gate;没 Outcome 不算完成;没 Causal Episode 不训 World Model;不做家庭总分/排名。
