SELFDRIVE_21D_V1

21天家长训练营 · 自驱不能奖励也不能逼

内在动机来自自主、胜任、关系三种体验;家长要支持这三样,而不是用奖励贿赂或用压力逼迫

看见与连接(D1–7) · 家长先改变(D8–14) · 共创与稳定(D15–21)

对象:家长(父母先改变;孩子不是被改造对象)

阶段 1 / 3

看见与连接

D1–7

Day 1看见与连接

先看见自己在用奖励和条件

技能:家长自我觉察

家长常用“做到就给”驱动

今日一件小事

记录今天你用了几次“你做到X就给你Y”。

今晚可以说的话

““我发现我总是用奖励来推你。””

观察什么(过程,非评分)

你靠外部条件驱动的频率

边界 / 提醒

先看见
