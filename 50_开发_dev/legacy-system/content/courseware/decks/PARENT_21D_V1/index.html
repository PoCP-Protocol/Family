PARENT_21D_V1

21天家长训练营 · 先连接再纠正

先连接/接住情绪,再纠正/解决;家长先练自己能改变的

看见与连接(D1–7) · 家长先改变(D8–14) · 共创与稳定(D15–21)

对象:家长(父母先改变;孩子不是被改造对象)

Day 1看见与连接

先看见自己的第一反应

技能:家长自我觉察(情绪教练第一步:先觉察情绪)

连接的前提是家长先不被自己的第一反应带走;情绪教练从"觉察情绪"开始。

今日一件小事

今天和孩子有摩擦时,先在心里说一句"我现在有点急",不马上开口。

今晚可以说的话

“我今天注意到自己有点着急,想先听听你怎么想的。”

观察什么

你自己的身体信号(皱眉/提高音量),不是给孩子贴标签。

边界 / 提醒

这是觉察练习,不是评判;若涉及安全风险,转人工/求助。

依据:E7 · doi:10.1016/j.adolescence.2015.04.005 E7 · doi:10.32920/26052868
Day 2看见与连接

开口前的三秒暂停

技能:家长情绪调节(暂停/降速)

一个短暂停能打断"施压→对抗"的升级链条。

今日一件小事

想批评前,先深呼吸数三秒再说第一句话。

今晚可以说的话

“等我一下,我想想怎么说更清楚。”

观察什么

暂停后对话是否更容易继续(过程观察,非打分)。

边界 / 提醒

暂停≠冷战;不是压抑,是给自己空间。

依据:E6 · doi:10.1017/S0954579414000169
Day 3看见与连接

接住情绪,而非先评判

技能:情绪确认(validate)

孩子先感到情绪被接住,才更能听进后面的话。

今日一件小事

把"你怎么又这样"换成"你看起来挺不开心的"。

今晚可以说的话

“看得出来这件事让你挺烦的。”

观察什么

说完之后孩子是更愿意说,还是更退缩。

边界 / 提醒

接住情绪不等于认同所有行为;安全边界仍在。

依据:E7 · doi:10.1016/j.adolescence.2015.04.005 E7 · doi:10.32920/26052868
Day 4看见与连接

先复述一句

技能:反映式/主动倾听

复述让对方感到"被听见"(felt-listening),降低防御。

今日一件小事

回应前,先用自己的话复述一遍孩子在意的点。

今晚可以说的话

“你的意思是……我理解得对吗?”

观察什么

复述后孩子有没有点头/补充("对,而且……")。

边界 / 提醒

复述是理解,不是审问;不追加评价。

依据:E2 · doi:10.1037/h0045357
Day 5看见与连接

少用"但是"

技能:降低防御(打断强制循环)

以“但是”抵消前半句连接;换成“我看到…”更少触发对抗。

今日一件小事

今天刻意不用"但是",改用"我看到…我有点担心…"。

今晚可以说的话

“我看到你很努力了,我也有点担心时间,我们一起看看?”

观察什么

去掉"但是"后,冲突是否少一点。

边界 / 提醒

不是不能表达担心,是换个不激化的说法。

依据:E6 · doi:10.1017/S0954579414000169
Day 6看见与连接

用好奇代替追问

技能:开放式提问

开放问题邀请孩子表达,封闭追问容易变审讯。

今日一件小事

把"为什么没做完"换成"今天卡在哪一步了?"

今晚可以说的话

“如果重来一次,你想怎么安排?”

观察什么

孩子回答的长度和主动性(过程,非对错)。

边界 / 提醒

好奇是了解,不是设套;不诱导认错。

依据:E2 · doi:10.1037/h0045357
Day 7看见与连接

第一周小复盘

技能:家长自我复盘(过程回看)

复盘看的是"哪次先连接让对话能继续",不是打分排名。

今日一件小事

回想这一周,记下一次"我先接住了情绪"的时刻。

今晚可以说的话

“这周我想谢谢你愿意跟我说话。”

观察什么

你自己的一个小改变,而非孩子"进步了多少"。

边界 / 提醒

复盘≠成绩单;完课不等于改变。

依据:practitioner · 证据待验
Day 8家长先改变

帮情绪起个名字

技能:情绪命名(labeling)

命名情绪帮助调节;是情绪教练核心一环。

今日一件小事

猜一猜孩子的情绪并说出来:"你是不是有点失望?"

今晚可以说的话

“这种感觉是不是有点像……失望/委屈?”

观察什么

命名对了时孩子的反应(常会松一口气)。

边界 / 提醒

是帮命名不是替他定义;猜错就问。

依据:E7 · doi:10.1016/j.adolescence.2015.04.005 E7 · doi:10.32920/26052868
Day 9家长先改变

示范如何平复

技能:共同调节(co-regulation)

家长先示范平复,孩子从中学会调节。

今日一件小事

情绪上来时,出声示范:"我先喝口水冷静一下。"

今晚可以说的话

“我刚才也有点冲,我们都缓一下再聊。”

观察什么

你平复的方式孩子是否开始模仿。

边界 / 提醒

示范真实的平复,不是表演完美。

依据:E7 · doi:10.32920/26052868
Day 10家长先改变

给有限选择

技能:自主支持(autonomy support)

有限选择既给自主感又守住边界,减少权力对抗。

今日一件小事

把命令换成两个都可接受的选择让孩子选。

今晚可以说的话

“你想先写数学还是先写语文?你来定。”

观察什么

给了选择后配合度的变化。

边界 / 提醒

选择在你能接受的范围内;不是放任。

依据:E6 · doi:10.1017/S0954579414000169
Day 11家长先改变

把"应该"换成"这个阶段可以先"

技能:期待校准

过高即时期待易生焦虑与冲突;分阶段更可达成。

今日一件小事

挑一个你常说"应该"的点,改成一个更小的当下目标。

今晚可以说的话

“这周我们先做到……就很好。”

观察什么

目标变小后,完成与情绪是否更好。

边界 / 提醒

校准期待≠降低关心;不制造"别人家孩子"的比较焦虑。

依据:practitioner · 证据待验
Day 12家长先改变

温和而坚定

技能:边界与温度并存

清晰一致的边界 + 温暖关系,比严厉或放任都更有效。

今日一件小事

选一个小边界,温和地说明并坚定守住一次。

今晚可以说的话

“我知道你还想玩,约定的时间到了,明天继续。”

观察什么

温和坚定 vs 发火,哪个孩子更配合。

边界 / 提醒

坚定不是强硬;守边界不靠吼。

依据:E6 · doi:10.1017/S0954579414000169
Day 13家长先改变

说到做到

技能:一致性(consistency)

一致性让边界可预期,减少试探与拉锯。

今日一件小事

守住一个昨天说过的小约定,不临时改。

今晚可以说的话

“昨天我们说好的,今天照做,谢谢你配合。”

观察什么

一致之后拉锯是否减少。

边界 / 提醒

一致≠死板;确需调整时先说明。

依据:E6 · doi:10.1017/S0954579414000169
Day 14家长先改变

第二周小复盘

技能:家长自我复盘(父母先改变)

看"我这周改变了哪个自己的小习惯",而非孩子变了多少。

今日一件小事

记下一个你自己坚持了的新习惯。

今晚可以说的话

“我在学着改变自己,也谢谢你陪我一起。”

观察什么

你自己的改变,不给孩子打分。

边界 / 提醒

打卡≠结果;别把复盘变成考核。

依据:practitioner · 证据待验
Day 15共创与稳定

邀请孩子共创一条规则

技能:共创(co-create)

孩子参与制定的规则更愿意遵守(自主+归属)。

今日一件小事

就一件小事,和孩子一起定一条双方同意的规则。

今晚可以说的话

“这件事我们一起定个都能接受的办法,好吗?”

观察什么

共同制定 vs 单方规定,执行度差别。

边界 / 提醒

共创不是甩锅给孩子;你仍是守护者。

依据:E6 · doi:10.1017/S0954579414000169
Day 16共创与稳定

做一次简单修复

技能:修复先于说教(repair)

没忍住之后,主动修复关系比继续讲道理更重要。

今日一件小事

为上次没忍住的时刻,向孩子简单道个歉。

今晚可以说的话

“上次我语气重了,对不起,我在学着改。”

观察什么

修复后孩子是否更靠近你。

边界 / 提醒

修复是真诚,不换取顺从;不反过来要求孩子先认错。

依据:E2 · doi:10.1037/h0045357
Day 17共创与稳定

具体地肯定一个小进步

技能:强化小赢(具体、非泛化)

具体肯定行为(而非贴"你真聪明"标签)更能巩固行为。

今日一件小事

指出一个具体的小进步:"你今天主动开始写作业了。"

今晚可以说的话

“我注意到你今天……(具体行为),挺不容易。”

观察什么

具体肯定后该行为是否更常出现。

边界 / 提醒

肯定行为不贴人格标签;不比较、不制造表扬依赖。

依据:E7 · doi:10.32920/26052868
Day 18共创与稳定

迁移到新场景

技能:泛化(generalization)

把一个已见效的小动作用到另一个场景,巩固技能。

今日一件小事

把本周一个有效的小做法,用到另一件事上。

今晚可以说的话

“上次那个办法挺好用,这件事我们也试试?”

观察什么

同一方法在新场景是否也管用。

边界 / 提醒

迁移是尝试,不强求每次都成。

依据:practitioner · 证据待验
Day 19共创与稳定

反复时不否定

技能:处理退步(不贴标签)

退步是常态;此时回到"先连接"比责备更有用。

今日一件小事

孩子退步时,先接住情绪,不说"你又……"。

今晚可以说的话

“有起伏很正常,我们从今天重新开始。”

观察什么

不否定 vs 责备,恢复速度差别。

边界 / 提醒

不否定≠没边界;红线仍守。

依据:E7 · doi:10.1016/j.adolescence.2015.04.005
Day 20共创与稳定

建立一个每日连接小仪式

技能:可持续的连接仪式

稳定的小仪式让"连接"跨天持续,而非一次性。

今日一件小事

和孩子约定一个每天 3 分钟的固定连接时刻(如睡前聊一句)。

今晚可以说的话

“以后每天睡前,我们聊一件今天的小事,好不好?”

观察什么

仪式坚持几天后关系的感觉。

边界 / 提醒

仪式贵在小而持续,不追求形式。

依据:E2 · doi:10.1037/h0045357
Day 21共创与稳定

综合复盘与下一步

技能:过程性回看 + 选择继续

看见 21 天里"真实发生的过程改变"(非总分),选一件继续做,自然衔接 90 天。

今日一件小事

回看 21 天,选一个你要继续保持的小习惯。

今晚可以说的话

“这 21 天我最想继续做的是……你觉得呢?”

观察什么

一个你确定要延续的改变(过程,非评级)。

边界 / 提醒

综合复盘不是结营考核;完课≠改变,改变靠继续做证明。

依据:practitioner · 证据待验
