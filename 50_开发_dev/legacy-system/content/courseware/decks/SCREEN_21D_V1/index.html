Day 1看见与连接

先看见自己的手机习惯

技能:家长自我觉察

家长常低估自己的使用;改变从看见自己开始。

今日一件小事

今天记录自己忍不住看手机的 3 个时刻。

今晚可以说的话

“我发现我自己也总忍不住看手机。”

观察什么(过程,非评分)

边界 / 提醒

先看见

Day 8家长先改变

从"没收"转"一起定"

技能:协商而非命令

共同定的规则执行度远高于单方规定。

今日一件小事

提议和孩子一起定一个手机小约定。

今晚可以说的话

“这个规则我们一起定,你觉得怎样合理?”

观察什么(过程,非评分)

孩子的参与程度。

边界 / 提醒

共定不是让孩子说了算;你仍是守护者。

依据:E6 · doi:10.1017/S0954579414000169 E7 · doi:10.1016/j.cpr.2014.04.003

Day 9家长先改变

给有限选择

技能:自主支持

有限选择支持自主、减少权力对抗。

今日一件小事

今晚可以说的话

观察什么(过程,非评分)

边界 / 提醒

两个选项都要是你能接受的。
