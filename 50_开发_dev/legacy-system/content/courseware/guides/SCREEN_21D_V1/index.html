SCREEN_21D_V1 · 讲师引导手册(DRAFT 脚手架)

21天家长训练营 · 手机不靠没收,靠一起定规则

先连接不先控制;家长先示范自己的手机习惯;把"没收"换成"一起定规则、逐步交还自主"

本手册状态 = DRAFT 脚手架:每课的"带练步骤/证据一句话"由课件内容确定性生成; 标 [待讲师/专家补] 的"具体话术、常见卡点与应对、现场分寸"须由**持证讲师/教研专家**补写并终审。AI 不代签、不判临床有效。

红线:父母先改变 · 不贴标签 · 不诊断手机成瘾 · 不制造焦虑 · 打卡不等于结果 · 完课不等于改变 · 观察不等于事实 · 不承诺戒手机 · 危机转专业 · 危机(自伤/家暴)→ 停课转人工。

Day 1 / 21看见与连接

先看见自己的手机习惯

本课目标

让家长练习「家长自我觉察」;理解:家长常低估自己的使用;改变从看见自己开始。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):家长常低估自己的使用;改变从看见自己开始。
  • 2. 示范(今晚可说的话):"我发现我自己也总忍不住看手机。"
  • 3. 布置今日一件小事:今天记录自己忍不住看手机的 3 个时刻。
  • 4. 说明观察什么(过程非评分):你自己的使用触发点(无聊/焦虑/习惯)
  • 5. 守边界/提醒:先看见

从"没收"转"一起定"

本课目标

让家长练习「协商而非命令」;理解:共同定的规则执行度远高于单方规定。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):共同定的规则执行度远高于单方规定。
  • 2. 示范(今晚可说的话):"这个规则我们一起定,你觉得怎样合理?"
  • 3. 布置今日一件小事:提议和孩子一起定一个手机小约定。
  • 4. 说明观察什么(过程非评分):孩子的参与程度。
  • 5. 守边界/提醒:共定不是让孩子说了算;你仍是守护者。
