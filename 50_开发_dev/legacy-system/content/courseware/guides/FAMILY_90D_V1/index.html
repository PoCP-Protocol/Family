FAMILY_90D_V1 · 讲师引导手册(DRAFT 脚手架)

90天家庭成长计划 · 从家长先改变到共创稳定

先连接/接住情绪再纠正;家长先练自己能改变的,再邀请孩子共创,最后把稳定的连接沉淀为家庭日常。

本手册状态 = DRAFT 脚手架:每课的"带练步骤/证据一句话"由课件内容确定性生成; 标 [待讲师/专家补] 的"具体话术、常见卡点与应对、现场分寸"须由**持证讲师/教研专家**补写并终审。AI 不代签、不判临床有效。

红线:父母先改变 · 不贴标签 · 不诊断 · 不制造焦虑 · 不比较排名 · 打卡不等于结果 · 完课不等于改变 · 观察不等于事实 · 危机转人工 · 危机(自伤/家暴)→ 停课转人工。

Week 1 / 13看见与连接

先看见自己的第一反应

本课目标

让家长练习「家长自我觉察(情绪教练第一步:先觉察情绪)」;理解:连接的前提是家长先不被自己的第一反应带走;情绪教练从觉察自身与孩子的情绪开始。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):这一周只做一件事——在冲突升起时先看见自己的身体信号和第一反应,先不开口纠正。 — 连接的前提是家长先不被自己的第一反应带走;情绪教练从觉察自身与孩子的情绪开始。
  • 2. 示范(可说的话):"我今天注意到自己有点着急,想先听听你怎么想的。"
  • 3. 布置每日微行动:摩擦升起时,先在心里默念一句"我现在有点急",不马上开口。 / 开口前给自己三秒暂停,深呼吸后再说第一句话。 / 留意自己的一个身体信号(皱眉/提高音量/胸口发紧)。 / 睡前记下今天最想改口的一句话。
  • 4. 说明观察什么(过程非评分):你自己的身体信号与第一反应,不是给孩子贴标签。
  • 5. 守边界/提醒:这是家长的觉察练习,不是评判孩子;若涉及安全风险,立即转人工/求助。

Week 2 / 13看见与连接

接住情绪,先复述再回应

本课目标

让家长练习「情绪确认(validate)与反映式/主动倾听」;理解:孩子先感到情绪被接住、被听见(felt-listening),防御下降,才更能听进后面的话。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):把评判换成接住;回应前先用自己的话复述一遍孩子在意的点。 — 孩子先感到情绪被接住、被听见(felt-listening),防御下降,才更能听进后面的话。
  • 2. 示范(可说的话):"看得出来这件事让你挺烦的,你愿意多跟我说说吗?"
  • 3. 布置每日微行动:把"你怎么又这样"换成"你看起来挺不开心的"。 / 回应前先复述一句:"你的意思是……我理解得对吗?" / 今天刻意不用"但是",改用"我看到……我有点担心……"。 / 把一次追问换成一句开放式问题:"今天卡在哪一步了?"
  • 4. 说明观察什么(过程非评分):说完之后孩子是更愿意说,还是更退缩(过程观察,非打分)。
  • 5. 守边界/提醒:接住情绪不等于认同所有行为;复述是理解不是审问,安全边界仍在。

Week 3 / 13家长先改变

帮情绪起个名字,并示范如何平复

本课目标

让家长练习「情绪命名(labeling)与共同调节(co-regulation)」;理解:命名情绪帮助调节,是情绪教练核心一环;家长先示范真实的平复,孩子从中学会调节。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):先帮孩子的情绪起个名字,再用自己出声的平复动作做示范。 — 命名情绪帮助调节,是情绪教练核心一环;家长先示范真实的平复,孩子从中学会调节。
  • 2. 示范(可说的话):"这种感觉是不是有点像……失望?我刚才也有点冲,我们都缓一下再聊。"
  • 3. 布置每日微行动:猜一猜孩子的情绪并说出来:"你是不是有点失望?" / 猜错就问,不替他定义:"那更像是……委屈?" / 情绪上来时出声示范:"我先喝口水冷静一下。" / 睡前回看:今天孩子有没有开始模仿你的平复方式。
  • 4. 说明观察什么(过程非评分):命名对了时孩子常会松一口气;你的平复方式是否被孩子模仿。
  • 5. 守边界/提醒:是帮命名不是替他贴标签;示范真实的平复,不是表演完美,更不诊断。

Week 4 / 13家长先改变

给有限选择,支持自主

本课目标

让家长练习「自主支持(autonomy support)与有限选择」;理解:有限选择既给孩子自主感又守住边界,能减少权力对抗与强制升级。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):把命令换成两个你都能接受的选择,让孩子来定。 — 有限选择既给孩子自主感又守住边界,能减少权力对抗与强制升级。
  • 2. 示范(可说的话):"你想先写数学还是先写语文?你来定。"
  • 3. 布置每日微行动:把一条命令换成两个都可接受的选择让孩子选。 / 选择由孩子定,你不在选完后又反悔。 / 观察给了选择后配合度的变化,不打分。 / 睡前记一次孩子自己做主后你没插手的时刻。
  • 4. 说明观察什么(过程非评分):给了选择后配合度的变化(过程,非对错)。
  • 5. 守边界/提醒:选择在你能接受的范围内,不是放任;把决定权交出去就不再临时收回。

Week 5 / 13家长先改变

期待校准与边界一致

本课目标

让家长练习「期待校准 + 温和而坚定的一致性(consistency)」;理解:过高的即时期待易生焦虑与冲突;清晰一致的边界加温暖关系,比严厉或放任都更有效。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):把一个"应该"改成"这个阶段可以先……",再温和坚定地守住一个小边界。 — 过高的即时期待易生焦虑与冲突;清晰一致的边界加温暖关系,比严厉或放任都更有效。
  • 2. 示范(可说的话):"这周我们先做到……就很好;约定的时间到了,明天继续。"
  • 3. 布置每日微行动:挑一个你常说"应该"的点,改成一个更小的当下目标。 / 选一个小边界,温和地说明并坚定守住一次。 / 守住一个昨天说过的小约定,不临时改。 / 睡前记:温和坚定 vs 发火,今天哪个孩子更配合。
  • 4. 说明观察什么(过程非评分):目标变小后完成与情绪是否更好;温和坚定 vs 发火,哪个更奏效。
  • 5. 守边界/提醒:校准期待≠降低关心,坚定不是强硬;不制造"别人家孩子"的比较焦虑,不排名。

Week 6 / 13共创家庭

邀请孩子共创一条家庭规则

本课目标

让家长练习「共创(co-create)」;理解:孩子参与制定的规则更愿意遵守(兼得自主感与归属感),减少单方规定引发的对抗。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):就一件具体小事,和孩子一起定一条双方都同意的规则。 — 孩子参与制定的规则更愿意遵守(兼得自主感与归属感),减少单方规定引发的对抗。
  • 2. 示范(可说的话):"这件事我们一起定个都能接受的办法,好吗?"
  • 3. 布置每日微行动:选一件小事,邀请孩子一起提议解决办法。 / 把你的底线说清楚,再在底线内和孩子协商。 / 定下一条双方都点头的规则,写下来贴出来。 / 观察共同制定 vs 单方规定,执行度差别。
  • 4. 说明观察什么(过程非评分):共同制定 vs 单方规定,规则执行度的差别(过程观察)。
  • 5. 守边界/提醒:共创不是把责任甩锅给孩子;你仍是守护者,安全红线不参与协商。

Week 7 / 13共创家庭

修复先于说教

本课目标

让家长练习「关系修复(repair)」;理解:家长没忍住之后,主动修复关系比继续讲道理更重要;修复本身示范了如何面对错误。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):为上次没忍住的时刻主动修复,而不是继续讲道理。 — 家长没忍住之后,主动修复关系比继续讲道理更重要;修复本身示范了如何面对错误。
  • 2. 示范(可说的话):"上次我语气重了,对不起,我在学着改。"
  • 3. 布置每日微行动:为上次没忍住的时刻,向孩子简单真诚地道个歉。 / 道歉只说自己,不附加"但你也……"。 / 修复后给一个具体的小连接(一起做件小事)。 / 睡前记:修复后孩子是否更靠近你。
  • 4. 说明观察什么(过程非评分):修复后孩子是否更愿意靠近你(过程,非交换)。
  • 5. 守边界/提醒:修复是真诚,不用来换取顺从;不反过来要求孩子先认错。

Week 8 / 13共创家庭

放大具体的小赢

本课目标

让家长练习「强化小赢(具体、非泛化)」;理解:具体肯定行为(而非贴"你真聪明"这类人格标签)更能巩固该行为,也支持孩子的情绪与自我调节。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):每天找到并具体说出一个孩子做到的小进步。 — 具体肯定行为(而非贴"你真聪明"这类人格标签)更能巩固该行为,也支持孩子的情绪与自我调节。
  • 2. 示范(可说的话):"我注意到你今天……(具体行为),挺不容易。"
  • 3. 布置每日微行动:指出一个具体的小进步:"你今天主动开始写作业了。" / 肯定行为本身,不加"你真聪明/真乖"的标签。 / 观察被具体肯定后,该行为是否更常出现。 / 睡前记一个你今天真心欣赏的具体行为。
  • 4. 说明观察什么(过程非评分):具体肯定后该行为是否更常出现(过程观察)。
  • 5. 守边界/提醒:肯定行为不贴人格标签;不比较排名,不制造表扬依赖。

Week 9 / 13共创家庭

迁移到新场景

本课目标

让家长练习「泛化(generalization)」;理解:把一个已见效的小做法用到另一个场景,能巩固技能并让改变不局限于单一情境。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):把本阶段一个有效的小做法,试着用到另一件事上。 — 把一个已见效的小做法用到另一个场景,能巩固技能并让改变不局限于单一情境。
  • 2. 示范(可说的话):"上次那个办法挺好用,这件事我们也试试?"
  • 3. 布置每日微行动:选一个近期有效的小做法,想想还能用在哪。 / 把它试着用到另一件事上,和孩子说清是在试。 / 观察同一方法在新场景是否也管用。 / 睡前记一次成功迁移或一次没成的尝试。
  • 4. 说明观察什么(过程非评分):同一方法在新场景是否也管用(尝试,非考核)。
  • 5. 守边界/提醒:迁移是尝试,不强求每次都成;不因一次没成而否定孩子。

Week 10 / 13稳定与沉淀

处理反复,不否定

本课目标

让家长练习「处理退步(回到先连接,不贴标签)」;理解:退步是常态;此时回到"先接住情绪"比责备更有用,情绪教练在起伏时仍先连接。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):孩子出现反复时,先接住情绪,不说"你又……"。 — 退步是常态;此时回到"先接住情绪"比责备更有用,情绪教练在起伏时仍先连接。
  • 2. 示范(可说的话):"有起伏很正常,我们从今天重新开始。"
  • 3. 布置每日微行动:孩子退步时,先接住情绪,不说"你又……"。 / 把退步当作数据而非罪证,想想触发点是什么。 / 用一句"我们从今天重新开始"代替翻旧账。 / 观察不否定 vs 责备,恢复速度的差别。
  • 4. 说明观察什么(过程非评分):不否定 vs 责备,孩子恢复的速度差别。
  • 5. 守边界/提醒:不否定≠没边界;不贴标签、不诊断,红线仍守。

Week 11 / 13稳定与沉淀

每日连接的小仪式

本课目标

让家长练习「可持续的连接仪式(family routines)」;理解:稳定、可预期的家庭日常与仪式化时刻,与儿童发展与家庭功能正相关,让连接跨天持续而非一次性。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):和孩子约定一个每天几分钟的固定连接时刻,并坚持下来。 — 稳定、可预期的家庭日常与仪式化时刻,与儿童发展与家庭功能正相关,让连接跨天持续而非一次性。
  • 2. 示范(可说的话):"以后每天睡前,我们聊一件今天的小事,好不好?"
  • 3. 布置每日微行动:和孩子约定一个每天 3 分钟的固定连接时刻(如睡前聊一句)。 / 把仪式放在每天同一时间,让它可预期。 / 仪式当天缺席就补一句说明,不无声跳过。 / 观察仪式坚持几天后关系的感觉。
  • 4. 说明观察什么(过程非评分):仪式坚持几天后关系与情绪的变化(过程观察)。
  • 5. 守边界/提醒:仪式贵在小而持续,不追求形式;打卡≠结果。

跨场景稳定

本课目标

让家长练习「跨情境稳定(把连接与边界带到更多场景)」;理解:把已稳定的连接与一致边界扩展到更多日常场景,让改变成为家庭默认方式而非特定场合的表现。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入本周焦点(为何有效):把前几周稳定下来的做法,带到吃饭/出门/作业等更多场景。 — 把已稳定的连接与一致边界扩展到更多日常场景,让改变成为家庭默认方式而非特定场合的表现。
  • 2. 示范(可说的话):"这些天我们在家做得挺好,今天出门也一样,我们一起。"
  • 3. 布置每日微行动:选一个新场景(如出门/吃饭),把先连接的做法用进去。 / 在新场景里同样保持温和而坚定的一致边界。 / 让每日连接仪式在忙碌的日子也不缺席。 / 观察哪些场景已经不太需要提醒就顺了。
  • 4. 说明观察什么(过程非评分):哪些场景已趋于稳定、不再需要刻意提醒(过程观察)。
  • 5. 守边界/提醒:稳定不是要求完美;不同场景有起伏很正常,不比较不排名。

综合复盘,衔接年度会员

本课目标

让家长练习「过程性回看 + 选择继续」;理解:看见 90 天里真实发生的过程改变(非总分),选定要继续做的事,自然衔接年度会员的长期陪伴。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 带家长回看:
  • 只谈"过程里发生了什么",不下结论、不评分。
  • 各自选"下一步继续做的一件事"。
