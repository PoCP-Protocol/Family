Day 1 / 21看见与连接

先看见自己的第一反应

本课目标

让家长练习「家长自我觉察(情绪教练第一步:先觉察情绪)」;理解:连接的前提是家长先不被自己的第一反应带走;情绪教练从"觉察情绪"开始。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):连接的前提是家长先不被自己的第一反应带走;情绪教练从"觉察情绪"开始。
  • 2. 示范(今晚可说的话):"我今天注意到自己有点着急,想先听听你怎么想的。"
  • 3. 布置今日一件小事:今天和孩子有摩擦时,先在心里说一句"我现在有点急",不马上开口。
  • 4. 说明观察什么(过程非评分):你自己的身体信号(皱眉/提高音量),不是给孩子贴标签。
  • 5. 守边界/提醒:这是觉察练习,不是评判;若涉及安全风险,转人工/求助。

Day 2 / 21看见与连接

开口前的三秒暂停

本课目标

让家长练习「家长情绪调节(暂停/降速)」;理解:一个短暂停能打断"施压→对抗"的升级链条。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):一个短暂停能打断"施压→对抗"的升级链条。
  • 2. 示范(今晚可说的话):"等我一下,我想想怎么说更清楚。"
  • 3. 布置今日一件小事:想批评前,先深呼吸数三秒再说第一句话。
  • 4. 说明观察什么(过程非评分):暂停后对话是否更容易继续(过程观察,非打分)。
  • 5. 守边界/提醒:暂停≠冷战;不是压抑,是给自己空间。

Day 3 / 21看见与连接

接住情绪,而非先评判

本课目标

让家长练习「情绪确认(validate)」;理解:孩子先感到情绪被接住,才更能听进后面的话。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):孩子先感到情绪被接住,才更能听进后面的话。
  • 2. 示范(今晚可说的话):"看得出来这件事让你挺烦的。"
  • 3. 布置今日一件小事:把"你怎么又这样"换成"你看起来挺不开心的"。
  • 4. 说明观察什么(过程非评分):说完之后孩子是更愿意说,还是更退缩。
  • 5. 守边界/提醒:接住情绪不等于认同所有行为;安全边界仍在。

Day 4 / 21看见与连接

先复述一句

本课目标

让家长练习「反映式/主动倾听」;理解:复述让对方感到"被听见"(felt-listening),降低防御。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):复述让对方感到"被听见"(felt-listening),降低防御。
  • 2. 示范(今晚可说的话):"你的意思是……我理解得对吗?"
  • 3. 布置今日一件小事:回应前,先用自己的话复述一遍孩子在意的点。
  • 4. 说明观察什么(过程非评分):复述后孩子有没有点头/补充("对,而且……")。
  • 5. 守边界/提醒:复述是理解,不是审问;不追加评价。

Day 5 / 21看见与连接

少用"但是"

本课目标

让家长练习「降低防御(打断强制循环)」;理解:以“但是”抵消前半句连接;换成“我看到…”更少触发对抗。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):以“但是”抵消前半句连接;换成“我看到…”更少触发对抗。
  • 2. 示范(今晚可说的话):"我看到你很努力了,我也有点担心时间,我们一起看看?"
  • 3. 布置今日一件小事:今天刻意不用"但是",改用"我看到…我有点担心…"。
  • 4. 说明观察什么(过程非评分):去掉"但是"后,冲突是否少一点。
  • 5. 守边界/提醒:不是不能表达担心,是换个不激化的说法。

用好奇代替追问

本课目标

让家长练习「开放式提问」;理解:开放问题邀请孩子表达,封闭追问容易变审讯。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):开放问题邀请孩子表达,封闭追问容易变审讯。
  • 2. 示范(今晚可说的话):"如果重来一次,你想怎么安排?"
  • 3. 布置今日一件小事:把"为什么没做完"换成"今天卡在哪一步了?"
  • 4. 说明观察什么(过程非评分):孩子回答的长度和主动性(过程,非对错)。
  • 5. 守边界/提醒:好奇是了解,不是设套;不诱导认错。

第一周小复盘

本课目标

让家长练习「家长自我复盘(过程回看)」;理解:复盘看的是"哪次先连接让对话能继续",不是打分排名。

建议时长

  • 各自选"下一步继续做的一件事"。

帮情绪起个名字

本课目标

让家长练习「情绪命名(labeling)」;理解:命名情绪帮助调节;是情绪教练核心一环。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):命名情绪帮助调节;是情绪教练核心一环。
  • 2. 示范(今晚可说的话):"这种感觉是不是有点像……失望/委屈?"

  • 5. 守边界/提醒:是帮命名不是替他定义;猜错就问。

本课目标

让家长练习「自主支持(autonomy support)」;理解:有限选择既给自主感又守住边界,减少权力对抗。

本课目标

让家长练习「期待校准」;理解:过高即时期待易生焦虑与冲突;分阶段更可达成。

带练步骤
