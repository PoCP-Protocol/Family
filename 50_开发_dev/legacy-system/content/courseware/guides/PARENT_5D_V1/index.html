PARENT_5D_V1 · 讲师引导手册(DRAFT 脚手架)

5天好爸妈入门训练营 · 先接住情绪,再谈教育

5天只练一件事——先看见并接住情绪,再连接、再沟通;情绪通了,方法才进得去

本手册状态 = DRAFT 脚手架:每课的"带练步骤/证据一句话"由课件内容确定性生成; 标 [待讲师/专家补] 的"具体话术、常见卡点与应对、现场分寸"须由**持证讲师/教研专家**补写并终审。AI 不代签、不判临床有效。

红线:父母先改变 · 不承诺提分或疗效 · 不比较排名 · 不贴标签 · 打卡不等于结果 · 完课不等于改变 · 观察不等于事实 · 危机转人工 · 危机(自伤/家暴)→ 停课转人工。

Day 1 / 5看见与接住

先看见自己的情绪反应

本课目标

让家长练习「家长情绪自我觉察」;理解:教育里第一个失控的常是家长的情绪;先看见自己

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):教育里第一个失控的常是家长的情绪;先看见自己
  • 2. 示范(今晚可说的话):"“刚才我有点急"
  • 3. 布置今日一件小事:记录今天你情绪一上来的 1 个时刻和当时的话。
  • 4. 说明观察什么(过程非评分):你自己的情绪触发点
  • 5. 守边界/提醒:先看见

Day 2 / 5看见与接住

先接住情绪·给情绪命名

本课目标

让家长练习「情绪确认与命名(情绪五维法·入门)」;理解:情绪先被看见和命名

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):情绪先被看见和命名
  • 2. 示范(今晚可说的话):"“你现在是不是有点生气/难过？我懂。”"
  • 3. 布置今日一件小事:孩子有情绪时
  • 4. 说明观察什么(过程非评分):情绪被命名后是否平缓一点。
  • 5. 守边界/提醒:“情绪五维法”官方逐日教案 【官方教案待补】;今天先练"命名情绪"这一步

Day 3 / 5连接与倾听

站到孩子角度看一次

本课目标

让家长练习「移情/换位(移情图·入门)」;理解:先理解他的处境

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):先理解他的处境
  • 2. 示范(今晚可说的话):"“换成是我在你这个位置"
  • 3. 布置今日一件小事:就今天一件冲突
  • 4. 说明观察什么(过程非评分):你能否说出他的感受与需要(而非只讲道理)。
  • 5. 守边界/提醒:“移情图”官方模板 【官方教案待补】;今天只练"说出对方感受"这一动作。

Day 4 / 5连接与倾听

先连接再说话

本课目标

让家长练习「主动倾听(先听后说)」;理解:先听懂再开口

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):先听懂再开口
  • 2. 示范(今晚可说的话):"“你先说"
  • 3. 布置今日一件小事:今天谈事前
  • 4. 说明观察什么(过程非评分):先听完后对话是否更少对抗。
  • 5. 守边界/提醒:倾听不是审问

Day 5 / 5定一件继续

定一件继续做的小改变

本课目标

让家长练习「选择与承诺」;理解:5天的意义不在学多

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):5天的意义不在学多
  • 2. 示范(今晚可说的话):"“这几天我最想继续做的是……你觉得呢？”"
  • 3. 布置今日一件小事:从这5天里选一个你要继续做的做法
  • 4. 说明观察什么(过程非评分):一个你确定延续的做法
  • 5. 守边界/提醒:入门营不承诺提分/疗效;它只是第一次小改变
