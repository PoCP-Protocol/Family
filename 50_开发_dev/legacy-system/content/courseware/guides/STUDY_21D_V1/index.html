STUDY_21D_V1 · 讲师引导手册(DRAFT 脚手架)

21天家长训练营 · 自驱不是催出来的

从催与监工,转向自主支持;帮孩子建立自我调节(定目标·拆小步·自评),家长少代劳、多肯定过程

本手册状态 = DRAFT 脚手架:每课的"带练步骤/证据一句话"由课件内容确定性生成; 标 [待讲师/专家补] 的"具体话术、常见卡点与应对、现场分寸"须由**持证讲师/教研专家**补写并终审。AI 不代签、不判临床有效。

红线:父母先改变 · 不承诺提分 · 不比较排名 · 不贴懒或笨的标签 · 打卡不等于结果 · 完课不等于改变 · 观察不等于事实 · 危机转人工 · 危机(自伤/家暴)→ 停课转人工。

先看见自己的催促模式

本课目标

让家长练习「家长自我觉察」;理解:自驱的第一道障碍常是家长的催;先看见自己。

建议时长

自学 10–15 分钟 / 团体带练 20–30 分钟(建议,按班型调整)

带练步骤
  • 1. 引入(为何有效):自驱的第一道障碍常是家长的催;先看见自己。
  • 2. 示范(今晚可说的话):"我发现我今天一直在催你。"
  • 3. 布置今日一件小事:记录今天催学习的次数和语气。
  • 4. 说明观察什么(过程非评分):你催的触发点与语气
  • 5. 守边界/提醒:先看见
