# 怎么做一个高质量、符合商业化的课件(方法论 V1)

> 适用:family 教育课件(家长/家庭)。承接 `COURSEWARE_AUTHORING_METHOD_V1.md`(六步循证生产)+ `courseware-author` v2 Agent。
> 一句话:**内容靠循证生成,专业靠人类背书,商业靠交付闭环与合规;三者缺一不能上市。**

## 0. 三个必须分开的"真相"
```
CONTENT_TRUTH   —— 内容生成出来了(YAML/deck)          ≠
EVIDENCE_TRUTH  —— 每条主张有真实可核 DOI + 诚实外推     ≠
COMMERCIAL_READY—— 专家签名 + 合规过审 + 消费闭环 + 真实验证
```
"生成出来"只完成第一层。把第一层当成品卖,是最常见的错误。

## 1. 高质量的判据(内容层)
1. **循证内核,不营销**:每个技能对应一个循证方法(情绪教练/家长管理训练/主动倾听…);来源用 `curl api.crossref.org` **逐条实核**,记 `verified:true` + 青少年**外推等级**(直接相关/MODERATE/LIMITED)。无来源标 `practitioner`,不硬凑 DOI。
2. **一课一技能、可执行**:每课时=一个可练技能 + **一件今天能做的小事**(不空泛、低剂量)+ 一句"今晚可说的话"示范 + "观察什么"(过程,非评分)+ 边界/免责。
3. **弧线连贯**:阶段递进(看见连接→家长先改变→共创稳定),不堆概念。
4. **红线内建**:父母先改变、不贴标签/不诊断、不制造焦虑/不排名、打卡≠结果、完课≠改变、观察≠事实、**不承诺疗效**、危机转人工。
5. **学习目标显性**:每课时写 learning_objective(学员学完能做什么),便于教学设计与评估。

## 2. 商业化的判据(成品层)—— Commercial Readiness Gate
| 门 | 要求 | 现状(PARENT_21D_V1) |
|---|---|---|
| EVIDENCE_BREADTH | ≥6 个 crossref 实核源;有青少年/沟通**直接相关**专源;外推诚实 | ✅ 已扩到 8 源(含 Parent-Teen Comm RCT / Triple P meta / IY RCT),全实核 |
| HUMAN_EXPERT_SIGNOFF | 持证教研/心理专家终审签名(涉未成年人/情绪,强制) | ❌ PENDING(AI 不可代签) |
| FACILITATOR_GUIDE | 讲师引导手册(带练/卡点/时长) | ❌ 缺 |
| PARENT_WORKBOOK | 家长工作簿/可打印物(可填写、可回收观察) | ❌ 缺 |
| VISUAL_MEDIA | 非纯文字:视觉系统/插画,必要时音视频脚本 | ⚠️ 仅 HTML/文字 deck MVP |
| ASSESSMENT_REPORT_LOOP | baseline→打卡→观察→Growth Report→复购 挂钩 | ❌ 未接产品 runtime |
| SEGMENTATION | 按年龄/冲突严重度/家庭结构分层 SKU,或明确单 SKU 边界 | ⚠️ 单轨,未分层 |
| COMPLIANCE | PIPL+未成年人+营销话术(不承诺疗效)+版权 过审 | ❌ 未审 |
| REAL_VALIDATION_PLAN | alpha(≈20家庭)→pilot(≈100家庭)测完成率/留存/可见变化 | ❌ 0 真实验证 |
| RUNTIME_BINDING | content_ref 接消费闭环,或明确 NOT_WIRED+授权状态 | ⚠️ NOT_WIRED / 授权 HOLD |

> 任一 ❌ 未过 = `CONTENT_DRAFT` / `EVIDENCE_READY`,**不得标 COMMERCIAL_READY**。

## 3. 从"生成的内容"到"能卖的课件"要补的六件事
1. **人类专家终审**:找持证家庭教育/心理专家逐课时审 + 署名;Agent 只能产"待签包",不代签。
2. **完整交付物**:讲师版(facilitator guide)+ 学员版(parent workbook,可打印/可填写)+ 视觉升级(母版/插画/无障碍)+(可选)短视频脚本。
3. **消费与复购闭环**:课件不是终点。接 baseline 测评 → 每日打卡 → 观察记录 → 阶段 Growth Report(诚实语言,非评分)→ 续购下一段(21天→90天)。这是复购的真正引擎。
4. **合规法务**:未成年人数据 PIPL、心理免责声明、销售页话术(不承诺"X天改变孩子")、引用方法/IP 版权。
5. **分层 SKU**:按孩子年龄段、冲突严重度、家庭结构出可组合变体;严重个案明确"转人工/转专家",不由课件承接。
6. **真实验证**:先 alpha(≈20 家庭)跑完整闭环看完成率/留存/可见变化,再 pilot(≈100 家庭);用真实数据修内容,而不是一次成型当真理。

## 4. 复用到任意课程(这才是商业价值)
以上不是只为 21 天写的。`courseware-author` v2 + 本方法 = **可复制的课件制造线**:换一份 course spec(对象/时长/问题域),同一流水线(循证→内容→讲师/学员物→设计→合规→质检→人签)即可产出新课(如"90天陪跑""青春期手机冲突")。质量与商业标准由**商业就绪门**统一守。
