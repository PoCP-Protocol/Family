## 一、循证家庭教育项目的通用课程范式(paradigm)

成熟的家长教育项目(parenting program)普遍是**技能建构式、多课时、家庭练习驱动**,而非知识讲授:
```text
诊断/评估 → 多课时技能建构(每课时练一个技能)→ 课间家庭小练习 → 复盘反馈 → 阶段巩固
贯穿:父母先改变(parent-first)· 每课时一个可练技能 · 练习在两次课之间发生 · 反馈闭环
```
> 该范式与榜样教育"父母先改变 + 21天每日小行动 + 90天四阶段"一致,也与本平台"每日一件小事 + 打卡 + 观察"一致。

## 二、真实循证方法/项目(方法可引证;已机器核验来源)

| 方法/项目 | 核心内容 | 我们的验证来源 | 证据 | 备注 |
|---|---|---|---|---|
| **情绪教练(Emotion Coaching)/ Tuning in to Kids·Teens (TinT)** | 家长识别并接住孩子情绪→帮助命名与调节→再引导问题解决;RCT 显示改善情绪社会化、降低冲突 | doi:10.1016/j.adolescence.2015.04.005 · doi:10.1037/dev0000875 | **E6–E7 / THIRD_PARTY_REAL** | 真实结构化家长项目;**"接住情绪"= 先连接再纠正的机制** |
| **强制家庭过程 → Parent Management Training(PMT/PMTO)** | 识别并打断"强制循环"(一方施压→另一方对抗/退让→升级);正向关注、清晰边界、一致后果 | doi:10.1017/S0954579414000169 | **E6 / THIRD_PARTY_REAL** | 早期儿童样本,外推青少年 LIMITED(见 CN-002) |
| **共情/主动倾听(Rogers 核心条件 → Gordon P.E.T.)** | 无条件积极关注 + 共情理解 + 真诚;复述/反映式倾听 | doi:10.1037/h0045357(Rogers) | **E2 / THIRD_PARTY_REAL**(理论背景,gate E4 FAIL) | 理论背景,不作效果定论 |
| Gottman 情绪教练 5 步 | 觉察情绪→视为亲近机会→共情倾听→帮助命名→设限并解决 | (Gottman 1996 待核验,未登记) | UNVERIFIED,非 decisive | 方法广为引用,**来源待核验后方可引** |

**内核共识(可引证)**:先**连接/接住情绪**,再**纠正/解决问题**;**家长先调节自己**,才谈孩子改变。这正是平台唯一干预 `LISTEN_BEFORE_RESPOND` 的循证内核。

## 三、课件(单课时)设计范式

每课时 = **一个可练的技能 + 一次家庭小练习**,建议统一结构(与平台响应六段同构):
```text
theme            今日主题(一个技能,不堆概念)
why/method_ref   方法依据(为什么有效)+ 证据引用(可引证处引真实来源;否则标 practitioner/pending)
parent_action    家长今日一件小事(低剂量、可执行,parent-first)
say_it_tonight   今晚可以说的一句话(话术示范)
look_for         观察什么(非评判、非贴标签;observation ≠ fact)
boundary         边界/免责(这是引导非义务;打卡≠结果,完课≠改变;危机转人工)
```

## 四、课程体系结构(对齐榜样教育 + Family Growth 维度)

```text
入口:家庭/父母测评(诊断优先级)
体验:21天家长训练营(每日一件小事;三周弧线)
  W1 看见与连接(D1–7)     觉察·倾听·接住情绪·降低自身反应
  W2 家长先改变(D8–14)    情绪调节·共情倾听·自主支持·期待·边界(PARENT_FIRST)
  W3 共创与稳定(D15–21)   与孩子共创规则·放大小赢·跨场景稳定
核心:90天四阶段(SEE→PARENT_FIRST→CO_CREATE→STABILIZE)
```
Family Growth 维度映射(供后续 grounding):P02 情绪调节 · P03 理解倾听 · P04 自主支持 · P05 期待 · P06 边界 · R03 沟通 · R04 冲突调节。

## 五、红线(课件必须守)
```text
父母先改变(不把孩子当被改造对象)· 不贴标签/不诊断 · 不制造焦虑/不比较排名
打卡 ≠ Outcome · 完课 ≠ 改变(结果靠真实行为改变证明)· 观察 ≠ 事实 · 顾问/点评 ≠ 事实
证据不硬凑:方法可引证处引真实来源;syllabus/课时数等细节待源核验,不编造 DOI/等级
危机(自伤/家暴)→ 不在课件内处理,转人工/安全通道
```

**对课件设计的可引证结论**:
- 循证家长项目普遍是**6–8 次课的技能建构 + 课间家庭练习**(TinK/DadsTIK 7 次课印证);21天营=把"多课时技能"拆成"每日一小步"的高频变体,机制一致。
- **情绪教练**(接住情绪→命名→调节→再引导)有 meta 级支撑(2024 meta;TinT RCT)——是"先连接再纠正"的循证内核,应作为 21天营主线技能。
- 结构化家长训练(Triple P/IY/PMTO)共识:**父母先改变 + 正向关注 + 清晰一致边界**。
