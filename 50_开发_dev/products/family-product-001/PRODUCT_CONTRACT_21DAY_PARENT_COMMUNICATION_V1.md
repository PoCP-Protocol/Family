## 一、产品承诺(Truth Guard)

**不承诺**:21 天改善孩子 / 关系提升 X% / 方法被证明有效。

**承诺**:
> 帮助家长用 21 天,形成**更稳定、可执行、可观察、可复盘**的亲子沟通实践。

即产品交付的是「家长侧可持续的沟通行为闭环 + 可见的观察记录」,不是对孩子结果的保证。

## 二、问题域(第一版只做一个)

亲子沟通冲突,典型触发:
```text
顶嘴 · 摔门 · 家长容易吼 · 不知道第一句话怎么说 · 冲突后不知如何修复
```
**不做**(本版):手机/学习动力/拖延/自驱/青春期全部问题。

## 三、21 天结构(复用现有能力,不新增 intervention)

| 阶段 | 内容 | 依赖的现有能力 |
|---|---|---|
| **Day 0** | WAF → Principal 对话 → Perspective → 确认当前 Growth Priority → Baseline Observation | WAF / Principal / GrowthPriority / OutcomeObservation |
| **Day 1–7** | 每天:One Small Action → 去做 → Check-in → Observation | GrowthAction / Check-in / Observation |
| **Day 7** | Weekly Growth Review | GrowthReview |
| **Day 8–14** | 依据 Observation + Review + NextStepDecision 调整 | NextStepDecision |
| **Day 14** | 第二次 Growth Report | Growth Report V1(读投影) |
| **Day 15–21** | 继续最有效的问题域 | — |
| **Day 21** | 21-Day Growth Review:我们试了什么 / 观察到什么 / 仍不确定什么 / 值得继续什么 / 下一个 Growth Priority | GrowthReview / Timeline |

关键:**每天是「一个小行动」,不是「一节课」**(与 LMS/课程平台明确区分)。

## 四、安全与升级

任一环节命中 REVIEW/HIGH_RISK(含 W2R-104 专家护栏 GOLD-051/053)→ 走 W2R-105 Human Gate(候选扣留 / 人工确认)/ 危机短路转人工。产品不绕过安全闸。

## 五、边界(冻结)

```text
不新增 canonical schema · 不新增 intervention/dimension/life-stage · 不做孩子 Agent · 不做课程平台/LMS
不做 Family Score/Ranking/因果结论 · 真实家庭数据未用 · 与 M3 Runtime 收口不争抢(不改 Family Core)
```

## 六、复购逻辑(为什么能卖)

```text
产品闭环(21天可完成)→ 成长记录(Growth Report 可见)→ AI 陪伴(Principal 每日陪练)
→ 续费(下一个 Growth Priority / 下一个 21 天)→ 数据库沉淀 → 平台生态
```
对标榜样教育成功经验:先「家长训练营 + AI 陪练 + 成长报告」,靠任务/反馈/可见变化形成复购,再长成平台。
