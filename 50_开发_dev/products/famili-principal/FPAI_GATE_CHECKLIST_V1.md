# FPAI Gate Checklist V1

## FP0 Required Gates

- [x] PRODUCT_BOUNDARY: independent `products/famili-principal` path exists.
- [x] BRAND_IDENTITY: source teacher and target persona are separated.
- [x] PERSONA_DNA: identity, values, language, thinking, action, relationship, boundary.
- [x] BOBO_SOURCE_REGISTRY: seed registry exists with conservative rights status.
- [x] CORPUS_USAGE_POLICY: no automatic T1 to T4 promotion.
- [x] TEACHER_MODEL: BTM defined without monolithic Bobo prompt.
- [x] METHOD_TAXONOMY: method families are named as FPAI extraction categories, not unsupported Bobo quotes.
- [x] SCENARIO_TAXONOMY: common family-growth scenarios defined.
- [x] DISTILLATION_SCHEMA: source lineage and review status required.
- [x] FAMILI_TRANSFORMATION_POLICY: identity mimicry removal required.
- [x] RESPONSE_CONTRACT: structured response contract exists.
- [x] ACTION_CARD_CONTRACT: action card is explicitly not Family GrowthAction.
- [x] SAFETY: normal/review/high-risk routing exists.
- [x] GOLD_EVAL_CASES: at least 100 cases.
- [x] MODEL_ARCHITECTURE: provider replaceable.
- [x] TRAINING_NOT_STARTED: true.
- [x] M2_RUNTIME_DEPENDENCY: 0.

## Exit Rule

FP0 may close as foundation-ready only if all gates pass and `START_FP1 = NO` remains true until owner authorization.
