# FPAI Visual Benchmark Rubric V1

**状态**: DRAFT · MM1-B0
**首版**: 2026-08-13
**上位**: `FPAI_MM1B_BENCHMARK_SPEC_V1.md` §7
**目标**: 为 Avatar Provider 的**主观视觉表现**建立 10 维评分,评估法咪莉形象是否达到"知性邻家姐姐"目标。

---

## 0. 使用规则

- 每维 **1–5 分**;不做总分,不做加权
- 每维**最低门槛**在 §11 中给出
- 至少 3 位评估者独立打分
- 观看**相同的 utterance 集** + **相同的 barge-in 用例** + **相同的空闲用例**
- **禁止**评估 provider 提供的"最佳 demo",必须用统一测试集

---

## 1. identity_stability · 形象稳定性

**问**: 同一次会话内,不同表情/角度/光照下,是否始终是"同一个人"?

| 分 | 判断 |
|---|---|
| 1 | 换个角度就换脸 |
| 2 | 表情剧烈时脸型漂移 |
| 3 | 大部分场景稳定 |
| 4 | 全程稳定 |
| 5 | 稳定且识别度高,一眼是她 |

**门槛**: ≥ 4(IP 核心,不稳定 = 无 IP)

---

## 2. natural_gaze · 自然凝视

**问**: 是否有"她在看我"的感觉,还是空洞盯着虚空?

| 分 | 判断 |
|---|---|
| 1 | 死鱼眼 / 明显盯屏幕右上角 |
| 2 | 偶尔看向摄像头 |
| 3 | 大部分时候看向摄像头 |
| 4 | 稳定看向摄像头,偶尔自然移开 |
| 5 | 有意图性凝视,偶尔自然转移 |

**门槛**: ≥ 3

---

## 3. subtle_expression · 微表情

**问**: 说到不同情绪内容时,表情是否有细微变化(而不是"大笑"或"皱眉")?

| 分 | 判断 |
|---|---|
| 1 | 无变化 / 机械 |
| 2 | 有变化但突兀 |
| 3 | 有细微变化 |
| 4 | 恰当细微 |
| 5 | 有层次,与内容深度对齐 |

**门槛**: ≥ 3

---

## 4. small_gesture · 小幅手势

**问**: 手势是否克制自然?不做**主播式夸张手势**?

| 分 | 判断 |
|---|---|
| 1 | 无手势 / 机器人 |
| 2 | 手势夸张 |
| 3 | 适度小手势 |
| 4 | 恰当且有意图 |
| 5 | 与语义对齐的克制手势 |

**门槛**: ≥ 3

---

## 5. lip_sync · 唇形同步

**问**: 唇形与音频是否对齐?

| 分 | 判断 |
|---|---|
| 1 | 完全不同步 |
| 2 | 大量延迟 / 提前 |
| 3 | 大部分同步 |
| 4 | 稳定同步 |
| 5 | 精确到音素级 |

**门槛**: ≥ 3

---

## 6. head_motion · 头部动作

**问**: 有无自然的点头 / 侧头 / 微微前倾?

| 分 | 判断 |
|---|---|
| 1 | 头部完全静止 / 机械 |
| 2 | 动作生硬 |
| 3 | 有动作但重复 |
| 4 | 自然多样 |
| 5 | 情感驱动的头动 |

**门槛**: ≥ 3

---

## 7. stillness · 静默质量

**问**: **不说话时**是否舒服?还是明显 idle 播放圈?

| 分 | 判断 |
|---|---|
| 1 | 明显 idle 循环 / 卡帧 |
| 2 | 循环感强 |
| 3 | 大体自然 |
| 4 | 呼吸感自然 |
| 5 | 静止时仍有"她在" |

**门槛**: ≥ 3(barge-in 后可能进入静默)

---

## 8. warm_presence · 温暖在场感

**问**: 看到她之后,是否愿意继续说下去?

| 分 | 判断 |
|---|---|
| 1 | 不适 / 冷漠 |
| 2 | 中性 |
| 3 | 有点友好 |
| 4 | 明显温暖 |
| 5 | "她愿意听我说" |

**门槛**: ≥ 3

---

## 9. non_uncanny · 不 uncanny

**问**: 有无"死人眼"、"塑料皮肤"、"AI 味太重"、"过度美颜"?

| 分 | 判断 |
|---|---|
| 1 | 明显 uncanny |
| 2 | 某些角度 uncanny |
| 3 | 中性,不惊悚 |
| 4 | 舒服 |
| 5 | 无违和 |

**门槛**: ≥ 4(uncanny 直接导致用户退出)

---

## 10. interrupt_recovery · 打断恢复

**问**: 用户打断后,avatar 是否**立即停止**并回到 LISTENING 状态?有无甩头 / 抖动 / 空档?

| 分 | 判断 |
|---|---|
| 1 | 打断无响应或响应错乱 |
| 2 | 有响应但抖动 |
| 3 | 停止但姿态僵硬 |
| 4 | 立即停止 + 自然回到 LISTENING |
| 5 | 有"她注意到你打断了"的过渡 |

**门槛**: ≥ 4(barge-in 的视觉呈现是产品核心)

---

## 11. 门槛汇总

| 维度 | 门槛 |
|---|---|
| identity_stability | ≥ 4 |
| natural_gaze | ≥ 3 |
| subtle_expression | ≥ 3 |
| small_gesture | ≥ 3 |
| lip_sync | ≥ 3 |
| head_motion | ≥ 3 |
| stillness | ≥ 3 |
| warm_presence | ≥ 3 |
| non_uncanny | ≥ 4 |
| interrupt_recovery | ≥ 4 |

任何一维中位数低于门槛 → Avatar 层**不合格**,不进入 shortlist 保留席位。
