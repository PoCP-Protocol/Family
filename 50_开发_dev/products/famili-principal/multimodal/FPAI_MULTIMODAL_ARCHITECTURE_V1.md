# FPAI Multimodal Architecture V1

## Goal

Establish a Family-owned multimodal embodiment layer for the existing FPAI principal intelligence without replacing the principal soul.

## Architecture

```text
User
  -> Text / Audio / Image
  -> Multimodal Turn Normalizer
  -> Safety Precheck
  -> Principal Orchestrator
  -> Principal AI (existing intelligence)
  -> Performance Planner
  -> TTS / Avatar / Visual Aid
  -> User
```

## Boundaries

- Reuse existing Principal AI intelligence.
- Do not create a second brain.
- Do not write into Family core systems directly.
- Keep model, STT, TTS, and avatar providers replaceable.

## Initial MM1 Scope

- Interactive chat
- Micro-lesson demo
- Family dialogue simulation
