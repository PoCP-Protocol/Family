# FPAI Voice Benchmark Rubric V1

**状态**: DRAFT · MM1-B0
**首版**: 2026-08-13
**上位**: `FPAI_MM1B_BENCHMARK_SPEC_V1.md` §6
**目标**: 为 TTS Provider 的**主观声音质量**建立 9 维评分,评估法咪莉声音是否达到"知性 + 温暖 + 自然 + 成熟 + 有判断 + 有亲近感 + 不说教"的 Voice IP 目标。

---

## 0. 使用规则

- 每维 **1–5 分**,1 = 完全不达标,5 = 完全达标
- **不做总分**,不做加权,不做"综合得分"
- 每维的**最低门槛**在 §11 中给出;任何一维低于门槛 → 该 provider 不进入下一轮
- 至少 3 位评估者独立打分,记录中位数与极差
- 评估**必须听相同的 utterance 集**(见 `FPAI_MM1B_BENCHMARK_SPEC_V1.md` §5)
- 至少覆盖 **NORMAL / 情绪场景 / HIGH_RISK-被拒/HUMAN_GATE 场景 / 长会话疲劳场景**

---

## 1. warmth · 温暖度

**问**: 声音是否让人感到"这个人愿意听我说"?

| 分 | 判断 |
|---|---|
| 1 | 冷漠 / 机械 |
| 2 | 客套但无情感 |
| 3 | 有一丝关心但不稳定 |
| 4 | 稳定温暖,像认识的朋友 |
| 5 | 有"她愿意等我说完"的耐心质感 |

**门槛**: ≥ 3

---

## 2. clarity · 清晰度

**问**: 每个字听得清吗?中英混说时是否含糊?

| 分 | 判断 |
|---|---|
| 1 | 大量含糊 / 卡壳 |
| 2 | 常见词清晰,人名/数字/英文单词吞字 |
| 3 | 大部分清晰,偶有含糊 |
| 4 | 清晰稳定 |
| 5 | 咬字精准,数字 / 英文 / 儿化音都准 |

**门槛**: ≥ 4

---

## 3. naturalness · 自然度

**问**: 停顿、连读、语流是否像真人?

| 分 | 判断 |
|---|---|
| 1 | 明显 TTS 机器感,句读均匀 |
| 2 | 稍有停顿但生硬 |
| 3 | 大体自然,但长句偶失控 |
| 4 | 自然,长句也稳 |
| 5 | 与真人难分,包含自然的呼吸/微停 |

**门槛**: ≥ 3

---

## 4. authority · 权威感

**问**: 说建议时,是否让人感到"她真的懂"?

| 分 | 判断 |
|---|---|
| 1 | 犹豫、不确定 |
| 2 | 有点主见但说服力弱 |
| 3 | 建议时语气坚定 |
| 4 | 稳,像"经验丰富的长辈" |
| 5 | 判断感明显但不高压 |

**门槛**: ≥ 3

---

## 5. closeness · 亲近感

**问**: 是否让家长感到"她像我熟悉的人",而不是"客服"?

| 分 | 判断 |
|---|---|
| 1 | 客服 / 播音腔 |
| 2 | 有点亲切但公式化 |
| 3 | 邻居感 |
| 4 | 熟人感,愿意继续说下去 |
| 5 | 有"她坐在你旁边"的物理距离感 |

**门槛**: ≥ 3

---

## 6. fatigue · 长时段疲劳

**问**: 连听 10 分钟后是否累?

| 分 | 判断 |
|---|---|
| 1 | 3 分钟就腻 |
| 2 | 5 分钟疲劳 |
| 3 | 10 分钟内可接受 |
| 4 | 15 分钟不累 |
| 5 | 20 分钟仍舒适 |

**门槛**: ≥ 3

---

## 7. emotional_appropriateness · 情感恰当性

**问**: 高风险场景是否**克制**?普通场景是否有温度?不能"甜过头"、不能"说教"。

| 分 | 判断 |
|---|---|
| 1 | 情绪与场景完全错位 |
| 2 | 常错位 |
| 3 | 大部分恰当 |
| 4 | 稳定恰当 |
| 5 | 恰当且有细腻层次 |

**门槛**: ≥ 4(因为这是 IP 核心)

---

## 8. pause_quality · 停顿质量

**问**: 想让用户"接一句"时,是否留出合适的停顿?

| 分 | 判断 |
|---|---|
| 1 | 无停顿 / 停顿突兀 |
| 2 | 停顿存在但机械 |
| 3 | 大部分自然 |
| 4 | 语义驱动的停顿 |
| 5 | 有"她在等你回应"的意图性停顿 |

**门槛**: ≥ 3

---

## 9. non-preachy · 不说教

**问**: 语气是否让家长觉得被评判?

| 分 | 判断 |
|---|---|
| 1 | 明显说教 / 居高临下 |
| 2 | 偶尔说教 |
| 3 | 中性 |
| 4 | 温和平等 |
| 5 | 完全无说教感,像"陪你一起想" |

**门槛**: ≥ 4(因为这是"不做家长评分"的语气实现)

## 11. 门槛汇总

| 维度 | 门槛 |
|---|---|
| warmth | ≥ 3 |
| clarity | ≥ 4 |
| naturalness | ≥ 3 |
| authority | ≥ 3 |
| closeness | ≥ 3 |
| fatigue | ≥ 3 |
| emotional_appropriateness | ≥ 4 |
| pause_quality | ≥ 3 |
| non_preachy | ≥ 4 |

任何一维中位数低于门槛 → 该 provider 在 Voice Rubric 层**不合格**,不进入 TTS shortlist 保留席位。
