# FPAI Roadmap V1

## Product Destination

`法咪莉校长` is a multimodal digital-human IP for family growth: an interactive AI principal that can eventually teach, converse, guide practice, and appear across text, voice, avatar, classroom, and companion experiences.

The roadmap is staged so the Soul, text intelligence core, and digital-human IP foundation can advance without prematurely activating cloning, production avatar runtime, or public multimodal launch.

## DH0 - Digital-Human IP Foundation

Status: PASS_CLOSED (Owner decision 2026-08-11).

```text

DH0_BLOCKERS = 0
OWNER_DECISIONS = 3/3

PUBLIC_BOBO_DISCLOSURE = NOT_PART_OF_FAMILI_PUBLIC_IDENTITY
```

Scope delivered: the Family-owned `法咱莉校长` digital-human IP Bible, visual direction, non-cloned voice direction, multimodal experience map, prototype acceptance criteria, and asset rights/provenance system (landed as a formal CSV SSOT).

Not in scope: voice cloning, likeness cloning, production avatar runtime, lip sync, public launch, model training, or Family M2 runtime integration.

DH0 ran in parallel with FP1 as an IP design and acceptance track. DH0 is not FP3 runtime and does not choose voice/avatar vendors or generate production assets. Low-cost static concept validation continues under DH0.5 (review-only), parallel to and subordinate to the P0 product-integration mainline.

## DH0.5 - Static Identity Concept Validation

Status: AUTHORIZED (review-only, Owner decision 2026-08-11).

Scope: turn the selected C Warm Intellectual Companion direction into a first comparable set of static concept candidates (C1/C2/C3) for owner review. All generated concept assets are labelled `CONCEPT_FOR_OWNER_REVIEW`, must be registered in the provenance CSV before entering a review pack, and must never be labelled final face, production asset, or avatar. A/B remain text fallbacks only.

Not in scope: final visual identity lock, avatar/voice/lip-sync runtime, vendor selection, model training, or any production asset pipeline.

## FP2 - Companion Workflow

Status: NOT_AUTHORIZED.

## FP3 - Voice / Avatar / Digital Human

Status: NOT_AUTHORIZED_FOR_RUNTIME_IMPLEMENTATION.

Future scope: implement public-facing multimodal IP expression after explicit owner authorization, rights review, safety review, and DH0 acceptance review.

DH0 may prepare the IP and prototype requirements. Voice cloning, likeness cloning, lip sync, real-time avatar, and digital-human production runtime remain outside FP1/DH0 and require explicit rights, consent, safety, and owner approval.
