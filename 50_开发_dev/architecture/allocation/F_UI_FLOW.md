## 需求→确认→匹配→选择(三步,家长可读)
```text
1 家长输入自述 → 平台复述:"我理解你现在最想先解决的是【今晚怎么重新开口】"  [对,就是这个] [不是,我想说…]
2 确认后:"现在最适合先做的是…" → 展示 ≤3 卡:
    · 和 Family AI 练一下第一句话(3 分钟)   · 看 60 秒:为什么马上讲道理常无效   · [若反复] 开始 7 天微计划
    每卡含 why_this / 局限;可能出现"今天先不用做,注意休息"(NO_ACTION)
3 家长点选某卡 → 进入该服务(AI 练习 / 内容 / 计划);未点选不自动开始
```
