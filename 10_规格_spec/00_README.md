# Family 家庭成长AI平台｜实施开发包 V1.0

本实施包基于 Family 总体方案与 FGAIM（Family Growth AI Implementation Methodology）拆解，
用于把现有家庭教育业务能力迁入统一 Family 平台，并逐步建设 Family Growth OS、AI Platform、
Knowledge Foundry、Outcome/Causal Platform 与 World Model。

## 统一实施原则

- 不是另起炉灶，而是把现有课程、训练营、测评、助教、顾问、专家、社群、活动、会员、SOP和客户资产迁入 Family。
- Commodity Capability（支付、订单、直播、基础CRM、基础教务等）优先复用/集成，不重复造轮子。
- Differentiating Capability（Family Account、Ontology、Growth Profile、Intervention、Outcome、AI Agent、Causal Learning）由 Family 自主建设。
- 所有AI能力必须进入 `State → Decision → Action → Outcome → Learning` 闭环。
- 先跑通一个真实家庭闭环，再扩场景、扩年龄、扩生态。
- 世界模型不是一期目标；先完成 WM1→WM3，再建设 Causal/World Model。
